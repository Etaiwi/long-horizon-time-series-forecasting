# Development archive

This directory preserves work that is not part of the final Weather/DLinear
submission path.

`etth1_patchtst/` contains:

- the original ETTh1 EDA and reconstruction notebooks;
- the PatchTST reconstruction;
- rejected and exploratory DLinear improvements;
- their configurations, result files, documentation, collaboration logs, and
  model implementations.

The archive is kept for transparency and to avoid deleting earlier work. Its
files are historical artifacts and are not maintained as a standalone runnable
package after the final-project restructuring. The corresponding runnable state
remains available in Git history before commit `172a0ab` and on earlier branches.

`tools/` contains development helpers that generated the final notebook files.
They are not needed to run or submit the project.
