# Final report

`final_report_draft.md` is the editable source for the final report. The final
PDF will be placed in this directory after the multi-horizon results are added
and the text is reviewed.

The required sections are:

1. Original architecture.
2. Paper results.
3. Reconstruction results.
4. Improved architecture.
5. Improved results.
6. Discussion.
7. References.

The two main notebooks contain the numerical and technical material for the
reconstruction and improvement. Notebook 3 supplies the optional
multi-horizon evaluation.
